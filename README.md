## Calculator app quick start

The calculator app lives in `src/calculator.js` and supports the four basic operations shown in the exercise image:

- addition (`+`)
- subtraction (`-`)
- multiplication (`*`)
- division (`/`)

Run it with arguments:

```bash
node src/calculator.js 2 + 3
node src/calculator.js 10 - 4
node src/calculator.js 45 * 2
node src/calculator.js 20 / 5
```

Run the tests with:

```bash
npm test
```
